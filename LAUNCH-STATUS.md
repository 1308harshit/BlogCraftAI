## 🛠 **TROUBLESHOOTING**

### **If Build Fails**
```bash

npm install
npm run build
```

### **If API Calls Fail**
- Check API keys in `.env.local`
- Verify OpenAI has credit
- Confirm Supabase project is active

### **If Deployment Fails**
- Check Vercel environment variables
- Verify all API keys are set
- Check build logs for errors
