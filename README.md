## 🚀 Quick Start (5 Minutes)

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Set up environment:**
   ```bash
   cp .env.local.example .env.local
   # Fill in your API keys (OpenAI, Supabase, Stripe)
   ```

3. **Deploy to Vercel:**
   ```bash
   npm run build
   vercel --prod
   ```

4. **Start lead generation:**
   ```bash
   cd scripts
   npm install
   npm run scrape-leads
   npm run daily-outreach
   ```
